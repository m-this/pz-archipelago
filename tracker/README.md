This is a Poptracker pack for the black-silver Poptracker (https://github.com/black-sliver/PopTracker). It works by just downloading the zip, and plopping it into the designated packs folder. No unzipping necessary.

If you run into any problems, feel free to write in the Planet Zoo thread in discord, in the future games section. (https://discord.com/channels/731205301247803413/1326681567665324082)
