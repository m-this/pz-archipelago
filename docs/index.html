Planet Zoo Archipelago

The Planet Zoo randomizer for Archipelago, in one exe.

The randomizer is the work of tinkieZo and LTSmash: the apworld, the mod and client and the PopTracker pack. pzap.exe repackages it: it installs the mod, runs the client, starts the game and opens PopTracker, with nothing else to install.

Download pzap.exe

Before the session

Whoever generates the multiworld needs planetzoo.apworld from the same release. Put it in Archipelago's custom_worlds folder, then generate the YAML template from the Archipelago launcher and fill in the options. The goal is to breed a Giant Panda.

Play

  1. Double-click pzap.exe. A page opens in the browser. Keep the black window open while you play: closing it removes the client's patches from the game.
  2. Close Planet Zoo, then press Install or update. The page finds the game through Steam; if it does not, give it the Planet Zoo folder.
  3. Enter the room address (archipelago.gg:38281), your slot name and the password if the room has one, and press Save and connect.
  4. Press Open PopTracker. It downloads once and opens on your slot.
  5. Press Launch Planet Zoo. In Planet Zoo, open Career, pick "ARCHIPELAGO ZOO" and start a new game. The client waits until it sees that park before it sends anything.

Back to the normal game

Press Put the vanilla game back on the page, with the game closed. A Steam update also undoes the install; the page then offers to install again.

Windows and antivirus warnings

pzap.exe is not signed, and it writes into the game's memory, which is what the client has to do to unlock permits and research. Windows SmartScreen will warn about it and some antivirus tools flag it. Every release lists the SHA-256 of its files in SHA256SUMS, and the exe carries a build attestation you can check: 

gh attestation verify pzap.exe --repo m-this/pz-archipelago

When something goes wrong

The page shows the last lines of the log. The full log is in %APPDATA%\pzap\logs. Open an issue with it.
