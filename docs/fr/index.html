Planet Zoo Archipelago

Le randomizer Planet Zoo pour Archipelago, en un seul exe.

Le randomizer est l'œuvre de tinkieZo et LTSmash : l'apworld, le mod et le client et le pack PopTracker. pzap.exe les réunit : il installe le mod, fait tourner le client, lance le jeu et ouvre PopTracker, sans rien d'autre à installer.

Télécharger pzap.exe

Avant la session

Celui qui génère le multiworld a besoin de planetzoo.apworld de la même release. Le mettre dans le dossier custom_worlds d'Archipelago, générer le modèle YAML depuis le launcher d'Archipelago et remplir les options. Le but : faire naître un panda géant.

Jouer

  1. Double-cliquer sur pzap.exe. Une page s'ouvre dans le navigateur. Garder la fenêtre noire ouverte pendant la partie : la fermer retire les patchs du client dans le jeu.
  2. Fermer Planet Zoo, puis cliquer sur Installer ou mettre à jour. La page trouve le jeu via Steam ; sinon, lui indiquer le dossier de Planet Zoo.
  3. Entrer l'adresse de la room (archipelago.gg:38281), le nom du slot et le mot de passe s'il y en a un, puis cliquer sur Enregistrer et se connecter.
  4. Cliquer sur Ouvrir PopTracker. Il se télécharge une fois et s'ouvre sur le slot.
  5. Cliquer sur Lancer Planet Zoo. Dans le jeu, ouvrir Carrière, choisir « ARCHIPELAGO ZOO » et lancer une nouvelle partie. Le client attend de voir ce parc avant d'envoyer quoi que ce soit.

Revenir au jeu normal

Cliquer sur Remettre le jeu d'origine, jeu fermé. Une mise à jour Steam défait aussi l'installation ; la page propose alors de réinstaller.

Alertes de Windows et des antivirus

pzap.exe n'est pas signé et écrit dans la mémoire du jeu, ce que le client doit faire pour débloquer permis et recherches. SmartScreen avertira et certains antivirus le signaleront. Chaque release liste le SHA-256 de ses fichiers dans SHA256SUMS, et l'exe porte une attestation de build vérifiable : 

gh attestation verify pzap.exe --repo m-this/pz-archipelago

En cas de problème

La page affiche les dernières lignes du journal. Le journal complet est dans %APPDATA%\pzap\logs. Ouvrir une issue avec.
